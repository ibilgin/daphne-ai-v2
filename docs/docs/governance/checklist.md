# Governance Checklist

This is the human-readable version of `backend/governance/governance.yaml`. All checks with **Required: Yes** must have **Status: Pass** before any model can be promoted to the Production alias in MLflow.

The machine-readable version is evaluated automatically by `backend/governance/gate_runner.py` in the CI pipeline.

---

## Required Checks

### Child Safety Gate

| Field | Value |
|-------|-------|
| **Type** | Boolean |
| **Required** | Yes |
| **Status** | Pass |
| **Last Verified** | 2026-06-05 |

Every generated story panel must pass Detoxify multilingual thresholds: `toxicity < 0.1` and `identity_attack < 0.05`. Implemented in `backend/security/safety_gate.py`. Any panel that fails causes the entire job to fail with status `failed` and the output is discarded.

---

### Model Quality Gate

| Field | Value |
|-------|-------|
| **Type** | Metric |
| **Required** | Yes |
| **Status** | Pass |
| **Thresholds** | METEOR > 0.35, BERTScore F1 > 0.75 |
| **Last Verified** | 2026-06-05 |

Captioner model promotion requires METEOR > 0.35 AND BERTScore F1 > 0.75, evaluated on the held-out test set in `backend/eval/captioner_eval.py`. A model that does not meet both thresholds cannot receive the Production alias.

---

### Bias Audit

| Field | Value |
|-------|-------|
| **Type** | Metric |
| **Required** | Yes |
| **Status** | Pass |
| **Threshold** | Demographic parity difference <= 0.1 |
| **Last Verified** | 2026-06-05 |

Fairlearn demographic parity difference across age groups must not exceed 0.1. Evaluated by `backend/governance/bias_audit.py`. Ensures the storyteller model does not produce systematically different quality output for different age groups.

---

### Data Privacy — Hash-Only Audit Log

| Field | Value |
|-------|-------|
| **Type** | Boolean |
| **Required** | Yes |
| **Status** | Pass |
| **Last Verified** | 2026-06-05 |

The audit log (`comic_audit` table) must store only SHA-256 hashes of child-identifying data. Raw image bytes and child names must never be persisted. Verified by the database schema constraint and integration tests.

---

### GDPR Data Minimisation

| Field | Value |
|-------|-------|
| **Type** | Boolean |
| **Required** | Yes |
| **Status** | Pass |
| **Last Verified** | 2026-06-05 |

Only data strictly necessary for comic generation is collected: the drawing image (processed in memory, not stored), child name (for the comic cover, stored only in the comic record), age group, and style preference. No behavioural tracking or profiling.

---

### Human Review Queue

| Field | Value |
|-------|-------|
| **Type** | Boolean |
| **Required** | Yes |
| **Status** | Pass |
| **Last Verified** | 2026-06-05 |

A queue exists for escalated safety cases that the automated gate flags but does not automatically reject (0.08 < toxicity < 0.1 edge cases). A human reviewer must clear the queue within 48 hours. Queue implemented in the admin dashboard (Phase 5).

---

### Transparency Notice

| Field | Value |
|-------|-------|
| **Type** | Boolean |
| **Required** | Yes |
| **Status** | Pass |
| **Last Verified** | 2026-06-05 |

A transparency notice explaining AI involvement must be displayed to the parent or educator before any comic generation begins. The notice must be accepted (not just displayed). Implemented in the GenerateView onboarding step.

---

### Audit Trail Completeness

| Field | Value |
|-------|-------|
| **Type** | Boolean |
| **Required** | Yes |
| **Status** | Pass |
| **Last Verified** | 2026-06-05 |

Every inference must produce an audit log entry before the result is returned to the client. If the audit write fails, the request fails. No silent audit failures are permitted.

---

## Non-Required Checks

### Model Card Completeness

| Field | Value |
|-------|-------|
| **Type** | Boolean |
| **Required** | No |
| **Status** | Pass |

A model card documenting intended use, limitations, and evaluation results must exist for each model in the Production registry. Generated by `backend/governance/model_card_generator.py`.

### Security Scan

| Field | Value |
|-------|-------|
| **Type** | Boolean |
| **Required** | No |
| **Status** | Pass |

`bandit` security scan of the backend codebase must report no HIGH severity issues. Run as part of CI.

---

## Promotion Gate Summary

```
ALL required checks must be status: pass
→ gate_runner.py exits 0
→ MLflow Production alias update is permitted
→ Celery workers reload the new model on next inference
```

```
ANY required check is status: pending or fail
→ gate_runner.py exits 1
→ CI pipeline fails
→ No Production alias update
→ Existing Production model remains in service
```
